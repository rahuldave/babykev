babykev.api

The contract: request and answer shapes, mapped onto the single pointer primitive.

Noul -> two options, no and yes; answer = p(yes) Choice -> one option per criterion; answer = the likeliest, probabilities by name, confidence Score -> one option per level, in order; answer = expected level, legend, probabilities by level

class Noul

source

A yes-or-no question.

Field Type Default Description
type Literal[‘noul’] required Marks the question as yes-or-no
instructions JSONContent required The question, as text or as structured content
criteria dict[str, JSONContent] | None None What no and yes mean, under the keys false and true. May be left out

choice_confidence

source

choice_confidence(p: list[float]) -> float

Measure how far the most likely option stands above a guess among len(p) options.

Parameter Type Default Description
p list[float] required The probability of each option
returns float 0 for a guess, 1 when one option has all the probability

score_confidence

source

score_confidence(p: list[float]) -> float

Measure how closely a score’s probabilities sit around the most likely level.

1 when one level has all the probability, 0 for a guess or anything as spread out. The expected distance from the most likely level is divided by the distance a guess would have: equal probability on every level, measured from the middle of the scale.

Parameter Type Default Description
p list[float] required The probability of each level, lowest level first
returns float 1 when one level has all the probability, 0 for a guess or anything as spread out

round_prob

source

round_prob(x: float) -> float

Round a number for output.

Four decimals keep a rounded distribution’s sum within 0.02 of 1 even with MAX_OPTIONS options. Two decimals did not: 77 equal options summed to 0.77.

Parameter Type Default Description
x float required A probability, or a number worked out from probabilities
returns float The same number to four decimals
